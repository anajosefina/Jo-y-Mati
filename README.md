# ¡NOS RECIBIMOS! — Jo y Mati

Invitación web para el 18 de diciembre de 2026, 12:00 (Argentina).

Incluye cuatro diseños, cuenta regresiva, ubicación en Google Maps, confirmación con Jo o Mati por WhatsApp y música Danza Kuduro con pantalla inicial para elegir si reproducirla.

## Publicar en un repositorio nuevo

1. Creá un repositorio **público** en GitHub (por ejemplo `invitacion-jo-mati`).
2. Entrá al repositorio y elegí **Add file > Upload files** (o **uploading an existing file**).
3. Subí **index.html**, **README.md** y la carpeta **assets** con todos sus archivos. No subas la carpeta contenedora: `index.html` debe quedar en la raíz.
4. Confirmá con **Commit changes**.
5. Entrá en **Settings > Pages**, elegí **Deploy from a branch**, rama **main**, carpeta **/(root)** y guardá.
6. Esperá a que GitHub Pages publique la web. La URL habitual será `https://TU-USUARIO.github.io/invitacion-jo-mati/`.

Para probarla antes de publicar, abrí `index.html` en tu navegador. El botón «Entrar con música» inicia el audio después del toque del visitante (los navegadores no permiten garantizar sonido automático sin interacción).

Los enlaces de ubicación y WhatsApp están incorporados en `index.html`.
